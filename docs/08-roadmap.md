# 08 — Roadmap

## Phase 0 — Hackathon MVP

### Goal
Reliable 5-minute demo and credible architecture.

### Build
- 16 defined screens
- seed/demo data
- deterministic analytics
- grounded AI questions
- campaign matching demo
- creator brief generation
- tourist itinerary generation
- one AR/living-heritage experience
- feedback loop

## Phase 1 — Pilot

### Goal
Pilot with a small set of tourism businesses and destinations.

### Add
- real tourism partner data
- destination QR check-ins
- hotel/homestay availability reporting
- creator campaign workflow
- verified business onboarding
- basic booking/enquiry integration
- richer feedback analytics

## Phase 2 — Government integration

### Goal
Move from prototype to tourism intelligence infrastructure.

### Add
- official tourism data ingestion
- role-based government accounts
- historical tourism dashboards
- district-level analytics
- event/campaign reporting
- source governance
- exportable briefing reports

## Phase 3 — Creator economy

### Add
- verified creator onboarding
- campaign marketplace
- platform analytics integrations where APIs permit
- fraud/anomaly detection
- payout workflow
- creator reputation
- local-language content packs

## Phase 4 — Intelligence

### Add
- demand forecasting
- capacity modeling
- destination balancing
- campaign optimization
- tourism infrastructure opportunity analysis
- scenario simulation
- destination sentiment trends

## Phase 5 — Regional network

Potential expansion to:
- Meghalaya
- Nagaland
- Mizoram
- Arunachal Pradesh
- Tripura
- Sikkim
- broader Northeast tourism network
